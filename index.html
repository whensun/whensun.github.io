Computer Science PhD Student

Theodorus Wensan Februanto

My research focuses on computer architecture, systems security, software verification, and LLM-assisted testing.

I am a PhD student in Computer Science at Arizona State University. I develop automated techniques to test computer systems against architectural specifications and software security requirements.

My work involves RISC-V processors, emulators, operating systems, hypervisors, firmware, and trusted execution environments. I am particularly interested in using large language models to automate specification analysis and test case generation.

My first-author paper on RISC-V ISA conformance testing has been accepted at the International Conference on Software Engineering (ICSE 2027).

I am advised by Prof. Adil Ahmad at the ASTeRiSC Research Lab.

01

Research Interests

RISC-V Systems

Understanding and testing architectural behavior across processors, emulators, operating systems, hypervisors, and firmware.

Specification-Guided Testing

Translating natural language specifications into machine-checkable rules and executable test cases.

Systems Security

Studying isolation, privilege boundaries, context switching, and security-sensitive architectural state.

LLM-assisted Systems Analysis

Using large language models to understand specifications, source code, and system documentation for automated testing and security analysis.

Operating Systems and Virtualization

Testing operating systems, hypervisors, and firmware, with a focus on context switching, privilege transitions, and architectural state isolation.

Computer Architecture and Verification

Developing automated validation techniques for instruction set architectures, architectural state, reference models, and processor behavior.
